# Glosario

## Conceptos de futuros

| Término | Definición en este repositorio |
|---|---|
| Señal | Evidencia concreta de un cambio que apenas empieza: un caso, una práctica, un dato fuera de lo normal. Es una pista, no una certeza. |
| Señal débil | Señal todavía marginal, con poca evidencia, que podría crecer o desaparecer. |
| Tendencia | Cambio sostenido que, en un contexto dado, transforma la conducta y la idiosincrasia de un grupo humano y se manifiesta de forma concreta. Se distingue de la moda pasajera (*hype*) (Dragt, citada en D25). |
| Megatendencia | Tendencia de escala global y largo plazo (décadas) que aterriza de formas distintas en cada lugar: envejecimiento, urbanización, cambio climático, digitalización. |
| Impulsor | Fuerza que empuja el cambio en el sistema. Se ordena con STEEP. |
| Incertidumbre crítica | Factor de alto impacto cuya dirección no se puede predecir. Las dos más importantes suelen ser los ejes de los escenarios. |
| Comodín | Evento de baja probabilidad y alto impacto que puede cambiar todo, como un sismo mayor o una pandemia. |
| Discontinuidad | Ruptura en una tendencia. |
| Escenario | Relato coherente y plausible de cómo podría ser el futuro, con su lógica, sus indicadores y las señales que hoy apuntan hacia él. No es una predicción. |
| Arquetipos de Dator | Cuatro futuros genéricos de la Escuela de Manoa: continuidad (o crecimiento), colapso, disciplina y transformación. |
| Cono de futuros | Esquema que distingue futuros posibles, plausibles, probables y preferibles a partir del presente. |
| Futuro preferible | El que se desea. Es un juicio de valor y se declara como tal. |
| Backcasting | Método que parte del futuro preferible y define hacia atrás los hitos necesarios para llegar a él. |
| Tres horizontes | H1: el sistema actual, que pierde ajuste. H2: las innovaciones de transición. H3: las semillas del futuro deseado. |
| Análisis causal por capas | Lectura en cuatro niveles: letanía (lo que se dice), causas sistémicas, visión del mundo y mito o metáfora. |
| CIPHER | Seis tipos de señal: contradicción, inflexión, práctica nueva, hackeo, extremo y rareza. |
| STEEP o PESTLE | Categorías para ordenar impulsores. STEEP: social, tecnológico, económico, ambiental y político. PESTLE: político, económico, social, tecnológico, legal y ambiental. |
| Base de conocimiento | Conjunto razonado y sistematizado de hechos recientes que sostiene una señal. Cada señal del diccionario D25 tiene una, enlazada por QR. |
| Investigación etnográfica de futuros | Método de Textor que recoge, en entrevistas, las imágenes de futuro deseado y temido de las personas. |
| Tenkuä | Taller de alfabetización de futuros para innovación social, diseñado por Karla Paniagua y Paulina Cornejo. |
| Imagen de futuro | Idea dominante sobre el futuro que tiene un grupo y que orienta sus decisiones. |
| Futuro oficial | El que asumen los planes de gobierno, casi siempre una continuidad optimista. |

## Conceptos sistémicos

| Término | Definición |
|---|---|
| Acervo | Lo que se acumula o se agota con el tiempo: infraestructura, flota, deuda, confianza. |
| Flujo | Lo que hace crecer o bajar un acervo: inversión, mantenimiento, viajes, subsidio. |
| Bucle de refuerzo (R) | Cadena causal que amplifica el cambio. |
| Bucle de balance (B) | Cadena causal que lo frena. |
| Demora | Tiempo entre una causa y su efecto. |
| Variable motriz | Variable que influye mucho y depende poco; suele ser una palanca. |
| Variable dependiente | Variable que depende mucho y influye poco; suele ser un buen indicador. |
| Arquetipo sistémico | Patrón de estructura que se repite y produce conductas reconocibles, como el desplazamiento de la carga o la erosión de metas. |
