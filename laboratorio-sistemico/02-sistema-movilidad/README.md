# 02 · El sistema de movilidad de la Ciudad de México

## Qué es el sistema

| Componente | Qué incluye |
|---|---|
| Propósito | Que las personas y los bienes lleguen a donde necesitan: trabajo, escuela, salud, cuidados, abasto, ocio |
| Personas usuarias | Quienes viajan, con sus diferencias de género, edad, ingreso, discapacidad y territorio |
| Modos | Metro, Metrobús, Trolebús, Tren Ligero, Cablebús, RTP, trenes suburbano e interurbano, concesionado, taxis y plataformas, motocicleta, bicicleta, caminata, auto privado y carga |
| Infraestructura | Vías, rieles, estaciones, CETRAM, carriles exclusivos, ciclovías, banquetas, cruces, estacionamientos, talleres y subestaciones |
| Instituciones y reglas | SEMOVI, organismos operadores, alcaldías, gobierno federal y del Estado de México, leyes, concesiones, tarifas y normas |
| Dinero | Tarifas, subsidios, presupuesto, deuda e inversión privada |
| Datos y tecnología | Pago, información, videovigilancia, datos abiertos, plataformas y logística digital |
| Territorio | Dónde se vive y dónde se trabaja; densidad y usos del suelo |
| Entorno físico | Clima, agua, suelo que se hunde, sismos, energía y calidad del aire |

**Límites:** el sistema es la Ciudad de México. La Zona Metropolitana del Valle de México entra como entorno cuando los viajes, las decisiones o los riesgos cruzan el límite.
